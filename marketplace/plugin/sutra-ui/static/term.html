Sutra — FAQ

The quick answers. Just type what you want; the rest is automatic.
Why the [brackets] before replies?
Sutra's governance header — it shows how your request was read (direction, risk). Cosmetic; ignore it.
What is "caveman mode"?
Shorter replies that save tokens. On by default. Toggle it in the sidebar, then Restart session.
What is /core:start?
It turns Sutra on. It runs automatically each session — you don't need to.
Why did it say BLOCKED or "not allowed"?
A safety gate fired. It will tell you exactly how to proceed — read the message and follow it.
Is this costing me money?
No extra charge. It runs on your existing Claude plan — same as the terminal. No per-message API billing.
How do I start?
Type what you want in plain English in the box and press Enter. Or click a button on the left.
What does "depth" mean?
Sutra's effort rating for a task, 1 (quick) to 5 (exhaustive). Just context.
It stopped or got interrupted?
Open Sessions (top right) and click Resume to pick up the conversation.
What can it actually do?
Read and edit files, run code and commands, research, and write documents — in the folder it's pointed at.
How do I stop it mid-task?
Click Ctrl-C in the Keys section (or press Ctrl-C).
Keyboard shortcuts (in the Claude window)
Ctrl-C — stop what it's doing
Ctrl-A — jump to start of the line
Ctrl-E — jump to end of the line
Ctrl-W — delete the word before the cursor
Ctrl-U — clear the whole line
Ctrl-L — clear the screen
Shift-Tab — switch mode (e.g. plan mode)
↑ / ↓ — previous / next in history
Mouse drag — select text to copy

Note: Mac shortcuts like Cmd-arrow or Option-arrow (jump/select by word) don't work here — this is a terminal, not a text box. Use the Ctrl keys above instead.
